Comecei do zero, sem curso e sem template: lendo documentação, quebrando código e refazendo. Hoje escrevo o front-end para o que aparece na tela e o back-end para o que acontece por baixo dela. A régua é a mesma dos times onde quero trabalhar — código limpo, problema entendido antes de abrir o editor, entrega honesta.

Como trabalho

  1. 01Entendo o problema antes de escrever a primeira linha.
  2. 02Começo pequeno, testo e cresço com pé no chão.
  3. 03Pergunto sem constrangimento e anoto o que aprendi.
  4. 04Deixo o código legível para a próxima pessoa — quase sempre eu.
